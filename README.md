## Run locally

1. Clone or download this repository.
2. Open `index.html` in a browser.
3. For live reload during development, open the folder in VS Code and use the Live Server extension.

The portfolio uses static HTML, CSS, and JavaScript and does not require npm or a build step.

## Publish with GitHub Pages

This project is in the `My-Portfolio` repository.

1. Open **Settings → Pages** in the repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose the `main` branch and `/(root)` folder, then save.
4. Wait for GitHub Pages to finish deploying. The repository's **Settings → Pages** section displays the published URL.
