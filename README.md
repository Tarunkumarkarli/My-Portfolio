# Tarun Kumar — Dark Interactive Portfolio

A responsive, dark-themed personal portfolio built with plain HTML, CSS, and JavaScript. No npm install or build step is required.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For the smoothest local experience, use VS Code with the Live Server extension.

## Personalize before publishing
Search `index.html` and replace:
- `Tarun Kumar` and the introductory copy as needed.
- `https://github.com/` with your GitHub profile and each project repository URL.
- `https://www.linkedin.com/` with your LinkedIn profile URL.
- `your.email@example.com` with your real contact email (both `mailto:` and the copy button).
- Project descriptions and placeholder Data Explorer project with accurate details.
- Skill tags so they reflect technologies you can confidently discuss.
- Add your resume as `assets/resume.pdf` (create the `assets` folder first). If you do not want a resume button yet, remove the Resume link from the navigation.

## Publish with GitHub Pages
1. Create a GitHub repository named `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root. Upload `assets/resume.pdf` too if using the resume link.
3. In the repository, open **Settings → Pages**.
4. Under build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for deployment and visit `https://YOUR-USERNAME.github.io`.

## Interactions included
- Animated rotating headline
- Responsive mobile navigation
- Scroll reveal animations
- Project category filters
- Project detail dialogs
- Copy-email interaction
- Cursor glow on desktop
- Reduced-motion accessibility support

Fonts load from Google Fonts; if unavailable, local fallback fonts are used. All portfolio content is static and can be hosted on GitHub Pages.
